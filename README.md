## Current projects

| Project | What it is |
|---|---|
| [**trading_bot_3**](https://github.com/daMarxrider/trading_bot_3) | An algorithmic trading platform for crypto and stocks. It has broker adapters, multi-source market data, a vectorized backtester, a GPU-accelerated genetic optimizer, a PyQt6 desktop app and a CLI, with cross-platform releases. This is the third version: [mk. I](https://github.com/daMarxrider/coinbase-pro-trader) (2020, archived), then a closed-source mk. II. The long-term goal is a full stock-analysis tool. |
| [**wfcalc**](https://github.com/daMarxrider/wfcalc) | A WARFRAME damage calculator and build optimizer. It has an exhaustive build search (CPU and WebGPU), a fight simulation using the game's own formulas, a web UI, a JSON API and a CLI built for developers and AI agents. Zero runtime dependencies. |
| [**web3-beefy-auto-withdraw**](https://github.com/daMarxrider/web3-beefy-auto-withdraw) | Watches Beefy vaults and withdraws funds automatically when the multisig schedules a call on a vault. |
| [**Bilibili_Anime4K**](https://github.com/daMarxrider/Bilibili_Anime4K) | A userscript that runs the [Anime4K](https://github.com/bloc97/Anime4K) upscaling filter in the browser for 2D anime on Bilibili and ACFun. It is a fork of [net2cn/Bilibili_Anime4K](https://github.com/net2cn/Bilibili_Anime4K); I added the YouTube upscaling support. |
| [**caelestia_user_configs**](https://github.com/daMarxrider/caelestia_user_configs) | My Hyprland / Caelestia desktop configuration, in Lua. |
